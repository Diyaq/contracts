## Size Limit

**Target:** 128 KB per contract (optimized)
**Source:** Stellar Documentation — "The network enforces a maximum contract size (currently 128KB on Mainnet, a value that can change with network configuration)" ([developers.stellar.org](https://developers.stellar.org/docs/build/smart-contracts/getting-started/hello-world))
**Safety Margin:** 10% (115.2 KB)

## Optimization Goals

### Phase 1: Immediate (Week 1)
- Measure all contract sizes
- Apply wasm-opt -O4 optimization
- Document baseline vs optimized sizes
- Identify contracts near 128 KB hard limit

### Phase 2: Short-term (Month 1)
- Extract shared code to libraries
- Remove unused dependencies
- Apply compiler optimizations
- Bring all contracts under 128 KB

### Phase 3: Long-term (Quarter 1)
- Continuous monitoring
- Prevent size regression
- Optimize new contracts
- Maintain <128 KB target

## Tracking

### Size Trends

Track size changes over time:
- Weekly measurements
- Compare against baseline
- Identify growing contracts
- Plan optimization work

### CI Integration

Automated size checks on every PR:
- Build and optimize all contracts
- Check against 128 KB limit
- Fail CI if limit exceeded
- Post size report as PR comment

## Success Criteria

✅ All contracts measured and documented
✅ Optimization applied to all contracts
✅ All contracts under 128 KB limit
✅ CI checks enforce size limits
✅ Documentation complete
